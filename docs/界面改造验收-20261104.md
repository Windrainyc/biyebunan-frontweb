# 三端界面改造与验收（2026-11-04）

## 已实现

- 管理端统一标题、卡片、表格密度与主次按钮，操作按钮整体换行而非拆字；保留浅蓝视觉。
- 关联字段统一紧凑可搜索分页下拉；支持必填反馈、Escape关闭、选中名称回显。
- 共用资源编辑与详情改独立页面，URL记录目标、筛选、排序和分页；未保存离开提供自定义确认，刷新重新读取授权数据。
- 知识状态标签展示真实总数，移除重复状态筛选；新增明确“保存草稿”，审核/发布/撤回等独立处理页给出步骤和结果说明。
- 表格增加总页数、跳页及已选筛选条件提示。
- 学生首页项目、交付和知识卡片直达目标记录；阅读页采用独立页面、长文排版、Markdown标题目录；项目空间保留当前项目上下文。
- 答疑会话使用服务端搜索，提供填入式提问模板，搜索后保持已选会话项目上下文；未触发模型请求。
- 素材库支持卡片/列表切换，上传过程显示上传、扫描、可用阶段。
- 中介工作台提供订单/项目直接入口；学生详情以实际studentId查询授权关联订单并分页，不读取私聊。
- 初次连接与异步页面提供加载反馈；仅静态资源开启gzip，不改变API/SSE。
