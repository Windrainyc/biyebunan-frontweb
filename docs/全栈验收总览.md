## 验证分层

- 后端最近完整测试76项、V56、249路由映射、30种DTO静态字段核对、严格JavaDoc与分层检查通过。
- 后端运行栈另有93个成功响应与7个错误响应通过实际HTTP OpenAPI校验；覆盖范围详见后端ui-response-contract-verification.json。
- 前端当前57项测试、TypeScript及Vite构建通过；生成契约版本1.0.28；页面承接矩阵只是源码索引。
- 三端独立前端镜像均已实际构建运行；API/worker0.33.0-dev独立镜像通过启动、健康及非root等检查。当前全栈组合为前端容器加宿主API/worker，不混称全部容器运行。
- 生产供应商、生产Collector、多节点HA、容量和跨机恢复均未验证；Docker Compose不等同多节点高可用。

## 尚未关闭的事项

1. 注册与中介激活需要真实服务协议URL/版本；当前缺失时明确禁用。浏览器新凭据输入及协议确认由用户操作，不能用API测试冒充页面提交成功。
2. 所有低频管理动作、更多数据量下的分页与浏览器负例仍需按矩阵逐项补齐；现有主要流程通过不能等同249项操作全验收。
3. 真实供应商账单查询、人工词元争议的受控更正、生产OSS、ASR/OCR等边界保留，不能宣称已具备。
4. 最终交付前核对两个仓库最新提交、镜像与运行快照一致，并重新核对相关变更；不重复无变化测试消耗额度。

全范围仍在接续，不删除automation-5。任何可用额度<=5%即保存断点并重排，恢复超过5%后继续。
