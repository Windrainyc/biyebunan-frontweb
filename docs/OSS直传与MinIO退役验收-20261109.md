# OSS 直传与 MinIO 退役验收（2026-11-09）

## 授权与范围

用户明确要求浏览器直传 OSS，不走后台文件上传；随后明确旧文件不迁移，删除旧 MinIO 文件及其关联数据库记录，保留用户、订单、项目、知识正文、聊天等业务主体。本次按后一次授权执行删除，未清空项目数据库。

## 实现

- Bucket：`biyebunanstudy`；区域 `cn-beijing`；官方 HTTPS 公网节点。未启用所提供 CNAME 或新增付费 CDN。
- 私有桶、阻止公共访问、版本控制、AES256 均通过项目安全检查；三端 Origin 的 PUT/GET/HEAD CORS 已配置。
- 密钥通过管理接口加密保存，未写入源码、报告或 Git。当前默认上传已切换 OSS。
- 前端上传仅发送元数据申请与完成回调；文件本体浏览器 PUT 到 OSS。上传目标必须是官方 HTTPS OSS 桶地址，不允许后台或其他域名，也没有后台上传回退。
- 按 images / videos / documents / codes 分目录，隔离上传与扫描后对象分离；下载绑定对象版本，签名 60 秒。
- 学生每次下载重新执行所属业务权限检查；数据库原子限额默认每账号 60 次/分钟、来源地址 180 次/分钟、每账号 1000 次/UTC 日。分别可用 ZX_DOWNLOAD_ACCOUNT_MINUTE、ZX_DOWNLOAD_NETWORK_MINUTE、ZX_DOWNLOAD_ACCOUNT_DAY 调整。
- 来源使用服务器解析的地址；云 API 无公网端口，经网关覆盖转发头后使用 FRAMEWORK 解析。数据库计数跨实例共享，任一额度不足整笔计数事务回滚，返回 DOWNLOAD_RATE_LIMITED / 429。
- 已删除 MinIO SDK、S3ObjectStorage、RoutingObjectStorage，以及旧迁移 worker/service/mapper/DTO/接口和前端迁移面板。历史 Flyway 文件保持不变；旧供应商枚举仅兼容历史读取，新配置禁止非 OSS。
- 本地环境 Compose、MinIO 镜像源码及初始化脚本已移除，相关启动与检查脚本已更新。未清空本地测试数据库或无关项目。

## 实际边界

限流计数衡量签发次数，不等于实际下载流量。签名有效期内可重复使用，已开始的传输可能在签名到期后继续；未宣称完全防盗刷或硬性费用封顶。没有启用 CDN/WAF 收费服务或执行大文件速度压测。

已验证小文本及 PNG，未逐一进行大视频、代码压缩包速度和所有格式预览验收。此次不宣称全平台或全部移动尺寸验收。

聊天中出现的长期密钥建议在 RAM 轮换，并将权限限定到本桶；项目支持重新加密保存新密钥。
