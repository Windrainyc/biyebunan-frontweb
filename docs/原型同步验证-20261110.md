# 原型样式落地验收（2026-11-10）

## 范围与授权

按仓库 docs/prototypes-20261110 中学生端和管理端完整原型落实主题与业务容器。用户于2026-11-10明确授权继续收尾、部署并推送指定Git分支。Java后端本轮仅更新设计契约与验收文档，未修改运行代码或数据库。

## 实现

学生端统一1320px内容、88px顶栏、蓝紫主题与圆角；工作台项目/待办/入口分区，知识库指南、独立搜索及轻量卡片，答疑桌面常驻资料栏、手机抽屉，项目交付左版本导航和右文件面板。项目概览/交付/答疑标签唯一标识，默认展示交付。

管理端统一222px侧栏、72px顶部、16px圆角和38px控件。项目增加真实阶段看板，可切回列表使用原业务操作；查看项目为620px侧拉详情，手机全宽，标题与关闭按钮可达，支持Escape关闭。首页快捷入口按服务端授权过滤。

## 验证

- 29个测试文件、136项测试通过；学生/管理/中介三端类型检查和构建通过。
- 实际隔离API与已有学生/管理员账户登录；1440×1060和390×844检查学生工作台、知识、答疑、项目、论坛及管理员总览、项目、订单，无整页横向溢出，无页面脚本错误。
- 实际项目概览/交付标签切换（仅一个选中）、看板/表格切换、详情Escape关闭、手机知识引用抽屉和手机详情关闭按钮可见通过。
- 对照离线原型检查布局、主题与比例。截图及机器记录见 reports/prototype-style-20261110。
- 未发起付费模型、短信、收款、交付发布或测试公告；未以原型示例数据替代真实接口。

## 真实业务适配边界

- 看板按当前筛选和当前页项目分组，不代表全库各阶段计数。
- 学生交付接口分页单位仍是文件；按本页releaseId分组，历史无releaseId文件独立显示。不是完整版本快照分页，页面已提示翻页查看更多文件。
- 原型假增长率、任务假勾选、虚构用户和内容不进入正式业务；导航按真实权限，图标沿用现有许可。没有声称全平台逐像素一致或全业务写入验收。
- 既有大型chunk与静态/动态重复导入警告保留，构建成功。
