# 订单、项目与运营改造

按用户十项反馈实施，保留现有浅蓝样式和权限隔离。已实现并部署云测试三端 orders-20261104，保持原IP入口。

1. 服务端生成时间加随机字符订单号，默认CNY；新增服务套餐配置及下拉。
2. 二级页面返回入口统一为标题上方紧凑返回按钮。
3. 订单/项目操作区统一紧凑按钮、换行、主次层级。
4. 状态及阶段原因可选，少字段操作改弹窗。
5. 收款凭证、支付流水、渠道、金额、时间和备注可选；缺失金额不计为真实到账。
6. 分配中介使用紧凑弹窗和可搜索下拉。
7. 删除无绑定、无收款、无项目引用的草稿或取消订单；已有账务/交付不级联删除。
8. 项目选择订单带入可修改标题、默认一周后交付；需求附件；移除里程碑操作与验收门槛；六类文件统一版本发布。
9. 运营埋点菜单：登录、浏览、知识学习及可见活跃时长；服务端身份、IP、时间，IP地点缺来源显示未知，不伪造历史。
10. ECharts统计大屏，使用真实统计接口，空数据/加载/失败明确区分。

验收覆盖：契约/JavaDoc/构建、状态和可选字段回归、删除保护、发布原子性、埋点去重与权限、三端浏览器与窄屏。后端已有三份验证JSON改动保留。

## 本轮验收结果

- 前端123测试通过，管理员/学生/中介三端类型检查及构建通过。ECharts大包提示为性能警告，图表按路由加载；未做并发压测。
- 浏览器真实管理员登录；自动订单编号隐藏、人民币默认、套餐3项选择；收款字段required均为false；中介下拉实际显示2个中介，弹窗关闭正常。
- 新增项目默认日期2026-11-11，选择订单自动带入标题，可编辑；未保存返回保护正常。
- 新增交付版本6类上传字段、发布按钮无文件时禁用、刷新/取消返回交付列表通过；修复旧原生template导致交付内容不显示及工作流新增路由切换。
- 真实统计3张ECharts图、活动记录菜单及IP归属地可见；活动名称和页面路径转换为中文，未知动作保留原值。
- 390px活动、统计、六类交付页面无整页横向溢出。截图见screenshots/orders-20261104。
- 公网API临时草稿自动编号、CNY和删除成功；双文件事务批次发布与幂等、无里程碑阶段推进以独立数据库集成测试为证据，未改动用户已有交付。

## 使用边界

删除仅允许无关联、未付款的草稿/取消订单；历史里程碑数据保留。每种交付类别本次一个文件，可将多文件整理为压缩包，未更新类别保留旧版本。活动从接入后开始记录；可见活跃时长不等于真实专注时长，IP地点为出口归属地。旧素材未迁移，不能因本轮上传改造宣称旧文件恢复。后端扩展旧对象存储场景有1项环境失败，详见后端docs/订单项目运营验收-20261104.md。
