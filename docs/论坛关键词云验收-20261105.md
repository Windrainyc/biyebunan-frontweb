# 论坛关键词云与社区改版验收（2026-11-05）

## 用户确认范围

用户明确选择关键词云并要求前后端按本版论坛实施。交流广场采用板块导航、讨论列表、社区侧栏；搜索使用框内放大镜；个人资料使用独立固定底栏右侧取消/保存；学生导航不显示数据统计。保留既有发帖、编辑、删除、审核、举报、回复及附件功能。

## 真实数据与权限

新增 GET /api/v1/student/forum/feed 与 /api/v1/student/forum/community，复用 get_student_posts 权限并校验学生平台。分页与计数使用相同范围；支持搜索标题、正文、板块、标签，板块筛选、本人发布、本人参与及最新/热度/待回复。

社区仅聚合启用板块内未删除的公开或锁定帖子。自己的待审帖仅可出现在其列表，不进入社区聚合；隐藏、删除评论及其直接回复不计入。活跃用户展示公开昵称、默认头像序号，未暴露电话或私有头像资产。

近七天热度 = 可见回复数 × 3 + 独立回复人数 × 5。热门取前三篇；活跃成员按公开发帖及回复贡献取前十二名。词云按近七天公开帖的真实标签和板块名称统计独立帖子数，同帖同名去重，最多十二词，点击搜索。没有数据时展示空状态；不是自动正文语义聚类。当前数据少时词云较稀疏。
