# 2026-11-10 原型设计基准

本目录保存这次用户要求同步的完整学生端、管理端静态原型快照。它们不是生产业务代码，所有演示数据、付款、发送通知与 AI 回答均不能当作真实业务实现。

- 学生端：`student/index.html`，五个主页面及弹窗交互全部包含在单文件中。
- 管理端：`admin/index.html`、`admin/style.css`、`admin/app.js`，包含十个模块及浏览器本地演示状态。
- 版本、文件大小和 SHA-256 见 `manifest.json`。原型源码逐字节复制，不修改现有在线原型。
- 原型在线地址仅用户本人可见，需要对应 ChatGPT 账户登录。离线可从本目录运行 `python3 -m http.server 18910`，分别访问 `/student/` 与 `/admin/`。

## 已确认视觉规则

学生端采用浅色蓝紫体系：背景 #f8f9ff、正文 #262840、次级文字 #687089、边框 #e6e8f2、主色 #665bea、浅紫 #eeebff、22px 主要卡片圆角。顶部导航、居中的内容区、项目主卡加待办侧卡、三张工具入口，以及轻量知识卡与讨论卡片流构成主要结构。

管理端使用背景 #f7f8fc、正文 #27293f、次级文字 #7e8499、边框 #eaecf4、主色 #6d5ce8、浅紫 #f0edff、16px 卡片圆角。桌面默认 222px 白色分组侧栏、72px 顶栏、紧凑筛选、轻量状态徽标、表格及详情操作。窄屏使用可收起导航和表格局部滚动。

真实项目必须保留服务端权限导航、真实统计、分页、加载/失败/空状态、真实交付版本和文件授权。原型中的演示名称、计数、模型回答、收款成功、通知发送、成员调整等不可以复制为生产结果。没有后端契约的交互应明确记为缺口。

本轮不扩展中介端视觉重做、不推送 GitHub、不部署正式站。
