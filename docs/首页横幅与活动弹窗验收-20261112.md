# 首页横幅与活动弹窗验收（2026-11-12）

## 确认范围
用户选择首页横幅方案，并明确授权前后端开发、测试后部署。位置为学生首页欢迎区下方、项目卡片上方；沿用 home-ads-options-20261112 的 A 方向，桌面高132px、390px手机高108px。

## 实现
- 管理端「基础配置 → 首页横幅」：真实分页、标题搜索、状态筛选、新增、编辑、排序、启停、删除、详情预览；新建默认停用。独立编辑页支持未保存离开提示。
- 配置标题、简短说明、可选横幅图片、可选完整海报、Markdown活动详情，至少海报或详情之一；数字越小越靠前。
- 学生首页最多展示前10条启用横幅，手动切换，当前页面可关闭；点击弹窗显示海报和排版后的正文，支持Escape关闭。空数据不占位。
- 图片复用私有素材库，限定就绪的PNG/JPEG/WebP/GIF共享素材。资产行锁与引用删除保护；仅已启用横幅的素材对学生开放。停用不撤销已经签发且尚未过期的短时下载授权。
- V76新增homepage_banner与权限；仅为已配置管理员导航补菜单，不覆盖旧菜单。管理员读写权限、学生读取权限分离；写入幂等、If-Match版本校验、审计与outbox。
- 不注入任何正式活动文案，不购买广告服务；没有定时投放、点击量统计或自动轮播。
